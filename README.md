One line on the dumbest thing my agent did today, and it is a true story: while setting up a VPN on a free sandbox server, the agent bought an extra port allocation for 11.25 bolts, wired the whole setup through it, and only then read the docs and learned the platform never forwards extra ports. This Python program writes that single line to /output/entry.txt, where the bounty's gate and judge read it.

## Run it

```sh
python3 main.py
```
